## Правила дома (применять ко всем каталогам)

1. **Телефон в первую очередь.** Минимумы на слайде 1280×720: название лота 30–34 px, описание 17–18 px,
   цена 28–32 px, мелкая спецификация ≥ 11 px. Плотные сетки (6+ лотов на странице) не используем.
2. **Сертификаты — без акцента.** Никогда не делаем сертификат смысловым блоком. Только мелкая
   строка-спецификация, и только три имени: **Beckett, JSA, PSA/DNA**. Другие сертификаты и названия
   магазинов в презентациях не пишем вообще.
3. **Подлинность не обсуждаем.** Нет слов «подлинный», «подлинность», «сертифицированный».
4. **Белое под вырезку, чёрное под кадр.** Вырезанный предмет (белый фон) → белая страница.
   Чёрный слайд — только если фон слайда сам является цельной атмосферной фотографией.
5. **Фото в полный кадр.** Половина слайда под фото = полноценный кадр во всю половину, без обрезанных краёв.
6. **Общая сумма — только для цельного пакета.** В предложении из разных опций итог не пишем.
7. **Реальные кадры вместо генерации.** Для тематических страниц — настоящий узнаваемый кадр.
   Генерация атмосферы только при отсутствии первоисточника.

## Структура каталога

```
обложка → разделитель главы → рабочие страницы лотов (крест 2×2 / диптих / триптих / мозаика)
→ соло для топ-лотов → индекс или лестница цен → финал
```

n08 (лот + сертификат — акцент на сертификате запрещён), n09–n12, n16, n17, n18, n21, n23–n26, n28,
n29, n31–n37, t18, t19, q02–q04, q09, x01–x04, k04, m08, m09, m13–m16, m21–m23, m26, m28,
все тестовые серии моделей (vo01–03, vs01–03, vh01–03, vl01–06, vl09–10, vc01–vc10).
