# Формат CSV для сборки презентации

Спецификация выгрузки, из которой собирается клиентский каталог. Отдать боту,
который делает выгрузку с портала.

## Технические требования

- Кодировка **UTF-8 с BOM** (`utf-8-sig`).
- Разделитель — **точка с запятой** `;`.
- Первая строка — заголовок с точными именами колонок из таблицы ниже.
- Поля, внутри которых есть `;`, кавычки или перевод строки, заключать
  в двойные кавычки; внутренние кавычки удваивать (`""`).
- Одна строка — один лот. Пустых строк между лотами нет.
- Имя файла — любое, удобно `<код>_<дата>.csv`, например `r43trk_15082026.csv`.

## Колонки

### Обязательные

| Колонка | Что кладём | Пример |
|---|---|---|
| `Название` | Полное название лота. Не сокращать: в деке оно печатается целиком. | `Boxing Greats Multi Signed Autographed Robe 51 Sigs Hearns Lewis BAS AC49467` |
| `Цена` | Цена продажи в рублях, целое число без пробелов и символов. | `2000000` |
| `Валюта` | Всегда `RUB`. | `RUB` |
| `URL главного фото` | Прямая ссылка на изображение. Для eBay — вариант `s-l1600`, не `s-l500`. | `https://i.ebayimg.com/images/g/jBoA.../s-l1600.jpg` |

### Важные

| Колонка | Что кладём |
|---|---|
| `Доп. фото` | **Ссылки на остальные кадры объявления, через вертикальную черту `\|`.** Сейчас этой колонки в выгрузках нет, и из-за неё у лота остаётся один-единственный кадр. Если бот может их достать — пусть достаёт: 2–4 дополнительных ракурса на лот. |
| `Сертификат` | Только `Beckett`, `JSA`, `PSA/DNA` — либо пусто. Номер сертификата можно дописать через пробел: `Beckett AC49467`. Другие названия и слово COA не писать: в деке они не показываются, строка просто выкидывается. |
| `Группа` | Метка для деления на главы: `ПЕРЧАТКИ`, `ХАЛАТЫ`, `Барселона`, `1996`. Лоты одной группы попадают в одну главу. Если группы нет — деление придумывается при сборке. |
| `URL на сайте` | Ссылка на карточку лота на stargift.ru — **только если лот действительно есть на сайте.** Тогда название в деке становится ссылкой. Для новых закупок оставлять пустым. |

### Необязательные

| Колонка | Что кладём |
|---|---|
| `Краткое описание` | Одна строка сути. Можно пусто — текст всё равно пишется заново. |
| `Полное описание` | Любые известные факты: размер, тираж, дата, событие, кто подписал. **Чем больше фактуры, тем точнее тексты в деке.** Сюда же — состав подписей, если он известен. |
| `Закупка USD` | Закупочная цена. В деку **никогда** не попадает, нужна только для внутренней сверки. |
| `eBay URL` | Ссылка на объявление. Полезна, чтобы дотянуть недостающие фото. |
| `Комментарий к фото` | Пожелание по кадру: `нужен кадр с автографом крупно`, `есть второй ракурс со спины`. |

## Чего в файле быть не должно

- Пересчитанных цен, скидок и наценок в клиентских колонках.
- Слов «подлинный», «подлинность», «сертификат подлинности» в описаниях —
  в деку такие формулировки не переносятся ни в каком виде.
- Названий магазинов и посредников (Propstore, LA Collections, ACOA и т. п.).
  Из сертификаторов допустимы только три: Beckett, JSA, PSA/DNA.
- Размеров в дюймах. Если в источнике дюймы — можно оставить, при сборке
  переводятся в сантиметры, но лучше сразу в см.

## Минимальный рабочий пример

```csv
Название;Краткое описание;Полное описание;Цена;Валюта;Сертификат;Группа;URL на сайте;URL главного фото;Доп. фото;Закупка USD;eBay URL;Комментарий к фото
Боксёрский халат Everlast, 51 автограф;Синий атлас, подписи серебром;51 подпись, среди них Томас Хирнс и Леннокс Льюис. Everlast, размер L.;2000000;RUB;Beckett AC49467;ХАЛАТЫ;;https://i.ebayimg.com/images/g/AAA/s-l1600.jpg;https://i.ebayimg.com/images/g/BBB/s-l1600.jpg|https://i.ebayimg.com/images/g/CCC/s-l1600.jpg;4999.99;https://www.ebay.com/itm/356545439296;нужен кадр со спины
```

## Что делать, если данных мало

Файл всё равно принимается: минимум — название, цена и ссылка на фото.
Остальное добирается при сборке. Но каждое незаполненное поле — это либо
лишний круг уточнений, либо более общий текст в каталоге. Больше всего на
качество деки влияют два поля: **`Доп. фото`** и **`Полное описание`**.
