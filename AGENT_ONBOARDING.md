# Передача агенту — что читать, что подключить, чем работать

Этот файл даёшь новому агенту первым. Всё, что дом умеет, лежит в этом
репозитории; отдельно нужно подключить только доступы — их в git нет и не будет.

## 1. Порядок чтения

1. **`CLAUDE.md`** — правила дома. Главный файл. Читать целиком и не нарушать:
   там осели все решения, которые Вашик принимал по ходу работы, включая те,
   что стоили переделок. Это не рекомендации, а требования.
2. **`HANDOFF.md`** — карта проекта: что за бренды, где что лежит, какие деки
   собраны и в каком они состоянии.
3. **`17_stargift/TEMPLATES.md`** — утверждённая библиотека форматов слайдов.
   Новые каталоги собираются только из них.
4. **`17_stargift/STYLE_TEXTS.md`** — как пишутся тексты лотов.
5. **`17_stargift/img_framing/README.md`** — каталогизированная база оформления:
   какая рама какому предмету и какой эпохе.

Вся активная работа — в `17_stargift/`. Папки `01`–`16` — второй бренд
(Relictum), там сайты, брендбук и промо; трогать их для задач Stargift не надо.

## 2. Чем работать — инвентарь инструментов

Все в `17_stargift/`. Это и есть «умения» в исполняемом виде: каждый инструмент
закрывает грабли, на которые дом уже наступил.

### Конвейер деки
| Инструмент | Что делает |
|---|---|
| `tools_pptx.sh` | Дека → редактируемый PPTX одной командой, с проверками до и после. Падает на любой из них. |
| `tools_deck_check.py` | До сборки: контент не уходит за срез и одно фото не стоит на двух слайдах. |
| `tools_deck_extract.py` | Снимает геометрию слайдов через Playwright → `geom.json` + `size.json`. |
| `tools_deck_to_pptx.py` | HTML → PPTX: текст живой, каждая картинка в своём media-файле. |
| `tools_pptx_verify.py` | После сборки: сверяет каждую картинку в готовом файле с декой перцептивным хешем. Ловит перестановки и подмены. |
| `tools_deck_pdf.py` | HTML → PDF. Размер слайда читает из `@page`, поэтому работает и для вертикали. |

### Обработка фотографий
| Инструмент | Когда брать |
|---|---|
| `tools_flatten.py` | Плоский лот снят под углом (программа, документ, фотография). Находит четыре угла листа и разворачивает настоящие пиксели. Подписи остаются 1-в-1. |
| `tools_whiten.py` | Предмет на сером фоне (стена, стол). Уводит фон в белый **без вырезания** — жёсткой границы нет, рвать нечему. |
| `tools_cutout.py` | Предмет на ровном студийном фоне, нужен PNG с прозрачностью. Даёт жёсткую границу — на неровном фоне не годится. |
| `tools_halfslide.py` | Кадр под половину слайда 8:9. Поле добирается фоном, предмет не кропается. |
| `tools_box_details.py` | Увеличенные фрагменты с подписями под пропорцию ячейки слайда. |
| `tools_master_sheet.py`, `tools_framing_catalog.py` | Мастер-листы для nano и каталог оформления. |

### Данные
- `tools_ebay_search.py` — официальное eBay Browse API. Страницы eBay из
  песочницы отдают 403, API — нет.
- `tools_site_select.py` — выборка лотов из CSV-выгрузки сайта.

### Сборщики каталогов — образцы для копирования
Пара «данные + сборка»: `tools_box_data.py` + `tools_box_build.py` (бокс,
9 лотов, самый свежий), `tools_mar_*` («Славные парни»), `tools_kat_*`
(Металлика и Depeche Mode), `tools_mj_build.py` + `tools_mj_vert.py`
(горизонталь и вертикаль). Новый каталог начинается с копии свежей пары.

### Зависимости
`pillow numpy scipy opencv-python-headless python-pptx pymupdf playwright`
(плюс `playwright install chromium`, либо готовый браузер в окружении).
Шрифты лежат в репозитории: `17_stargift/fonts_ttf/`.

## 3. Что НЕ передаётся с репозиторием

Секретов в git нет по правилу дома (см. `.gitignore`), поэтому доступы
подключаются на стороне агента отдельно:

| Доступ | Как подключить |
|---|---|
| **GitHub** | Вашик добавляет агента в коллабораторы `VashikMart/relictum`: Settings → Collaborators and teams. Либо даёт доступ своему GitHub App. |
| **Higgsfield** (генерация картинок) | MCP-сервер под аккаунтом агента. Проверить баланс до работы: сейчас кредиты на нуле, и часть задач приходится закрывать геометрией вместо генерации. |
| **eBay Browse API** | `client_id` / `client_secret` положить в `~/.ebay.env`. В git не коммитить никогда. |
| **Gemini API** | `GEMINI_API_KEY` в переменных окружения — запасной путь генерации, когда nano блокирует картинку. |
| **Порталы шаблонов** | Артефакты на claude.ai, идентификаторы в `HANDOFF.md`. Открываются под аккаунтом Вашика. |

Переписка прошлых сессий с репозиторием не передаётся и не нужна: всё
существенное из неё уже сведено в `CLAUDE.md`.

## 4. Быстрый старт

```bash
# репозиторий тяжёлый (~1.7 ГиБ истории) — для работы хватает поверхностного клона
git clone --depth 1 https://github.com/VashikMart/relictum.git
cd relictum/17_stargift

# собрать деку → проверить → PDF → PPTX
python3 tools_box_build.py                       # даёт deck_box_H.html
python3 tools_deck_check.py deck_box_H.html
python3 tools_deck_pdf.py deck_box_H.html out.pdf
./tools_pptx.sh deck_box_H.html out.pptx         # проверки внутри
```

Ветка активной работы — `claude/stargift-presentation-template-6gywk4`.

## 5. Пять правил, которые дороже всего нарушить

Полный список — в `CLAUDE.md`, но эти повторялись чаще прочих:

1. **Ни слова о подлинности.** Ни «подлинный автограф», ни «сертификат
   подлинности». Сертификатор можно назвать мелкой строкой и только из тройки:
   Beckett, JSA, PSA/DNA. Никаких других имён и никаких магазинов.
2. **Одно фото — один слайд.** Фотография лота не ставится ещё и на обложку или
   разделитель. Проверяется автоматически, сборка PPTX на этом падает.
3. **Кегли — минимальные.** Деку смотрят с телефона. Не влезает текст — режем
   текст или меняем раскладку, но не кегль.
4. **Фото лота не кропаем.** Не влезает в сетку — меняется раскладка под фото,
   а не фото под раскладку.
5. **Финальная выдача всегда редактируемая:** PPTX (открывается в Keynote)
   плюс PDF для просмотра. Отдельно просить об этом не нужно.
